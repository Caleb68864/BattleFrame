This module implements the mechanics of **Full Thrust**, the starship-combat game by
**Jon Tuffley**, published by **Ground Zero Games (GZG)**.

- Original work: *Full Thrust* (2nd Edition, Full Thrust Light, More Thrust, Fleet Books) —
  https://www.gzg.com
- Author / publisher: Jon Tuffley / Ground Zero Games

This module ships **the game mechanics only** — no rulebook text, no stat blocks, no faction
ship lists, and no artwork. It reproduces none of the copyrighted rules text or fleet data.
Players **bring their own ship designs**, entering them on the ship sheet (or using the
Mass/Points design helpers). This is an independent implementation of the game's mechanics for
the BattleFrame system, provided free of charge and **not for sale**.
