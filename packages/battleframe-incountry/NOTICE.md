# NOTICE — BattleFrame: InCountry

This module implements the **mechanics** of *INCOUNTRY (INX 2.0)*, a modern
tactical skirmish wargame by **Echo Dark Studios LLC** (https://inxcountry.com).

## What this module is

A rules **engine** for the BattleFrame system. It encodes how INX's mechanics
work — the d10 roll-under attack, the armor check, suppression, reactions,
initiative, and activation order — and lets you enter your own unit data.

## What this module is NOT

It ships **no ruleset content**:

- no rulebook text, prose, or flavour;
- no artwork;
- no proprietary unit stat blocks, weapon tables, scenario text, or card text.

Game mechanics and numeric values are facts and are not the expression that
copyright protects; this module reproduces none of INX's copyrightable
expression. To play, you supply your own unit and weapon values (from a rulebook
or army list you own).
