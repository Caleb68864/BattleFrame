# Alpha Strike Quick-Start Rules Are Genuinely Free (the user was right)

**The user's belief that "the Alpha Strike ruleset might be free out there" is CORRECT — with an important qualifier.**

A free, official, Catalyst-published Alpha Strike quick-start PDF exists and has existed for a decade.

## Editions (confirmed)

| Edition | Year | Notes |
|---|---|---|
| Alpha Strike Quick Start Rules | 2015 | 39pp, free PDF, cover by Anthony Scroggins |
| Alpha Strike Quick Start Rules: **Commander's Edition Update** | 2019 | Superseded the 2015 ed.; aligned to *Alpha Strike: Commander's Edition* |
| Alpha Strike: Quick-Start Rulebook (3rd Printing) | 2026-01 | Box-set insert; URL seen in search index |

The file `Alpha Strike Quick Start Rules 2019-08.pdf` was served from Catalyst's own free-downloads page (confirmed in the Internet Archive, HTTP 200 as of 2025-07-14).

## What the free QSR contains (confirmed via Sarna)

> ALPHA STRIKE BASICS, COMPONENTS, SETUP, PLAYING THE GAME, MOVEMENT PHASE, COMBAT PHASE, END PHASE, SPECIAL ABILITIES

Plus three scenarios (Training Day, Noble Feud, Factory Battle), reference tables, and **printable templates and cards**.

## The qualifier that matters

"Free" here means **zero-cost download**, published by the rights-licensee. It does **not** mean:
- an SRD
- an open licence
- permission to redistribute or reimplement

There is no Alpha Strike SRD. See [[free-to-read-vs-free-to-ship]] and [[alpha-strike-free-vs-paid-boundary]].
