# Topps Owns the BattleTech Tabletop IP

The BattleTech intellectual property is **not** owned by Catalyst Game Labs. Catalyst is a *licensee*.

The Master Unit List — an official, Catalyst-branded site — carries this footer, read directly:

> © 2026 - 2001-2010 The Topps Company, Inc.
> Mechwarrior, BattleMech, 'Mech and Aerotech are registered trademarks of The Topps Company, Inc.

MegaMek's own `LICENSE` file states the same chain, and adds a fourth party:

> MechWarrior, BattleMech, 'Mech and AeroTech are registered trademarks of The Topps Company, Inc. All Rights Reserved.
> Catalyst Game Labs and the Catalyst Game Labs logo are trademarks of InMediaRes Productions, LLC.
> **The BattleTech name for electronic games is a trademark of Microsoft Corporation.**

## Why this matters for a Foundry VTT module

There are **three** rights-holders to reason about, not one:

| Party | Holds |
|---|---|
| The Topps Company | Core BattleTech tabletop IP, trademarks |
| Catalyst Game Labs (InMediaRes) | Tabletop publishing license |
| Microsoft | **The BattleTech name for *electronic games*** |

A Foundry VTT module **is an electronic game**. That drops it squarely into the *Microsoft* trademark lane, not merely the Catalyst tabletop lane. This is the single most under-appreciated fact in this research and it materially changes the risk analysis.
