# Reserve Power Allocation

Each round in the Command Phase, a ship receives **Reserve Power Points**, tracked physically as **cubes placed on boxes/abilities at the bottom of the ship card**.

Confirmed:
- "The better your engines, the more reserve power cubes you will have to use on the various boxes/abilities at the bottom." → **Reserve power is a function of current Engine value**, not a fixed stat. See [[engine-damage-death-spiral]].
- A ship that voluntarily powers down "has no Reserve Power Points" ([[drifting-and-voluntary-power-down]]).

Reviewers single this out as the game's best feature: "super-slick energy allocation and combat system, all managed on ship cards. This is very, very well designed."

**Not found:**
- The exact formula converting Engine value → number of cubes.
- The full list of what boxes/abilities cubes can be spent on.
- Whether unspent cubes carry over between rounds (**assume not — but this is unverified**).

**Engine note:** this is a per-round, per-ship resource pool that is *derived from a damageable stat*. It is the main coupling point between the damage model and the action economy. See [[ship-card-is-the-state-container]].
