# Rejected Candidates: Other Fat Dragon Games Wargames

The dictation garbled to "Battlefield Valkyrie / Battleship Valgary". **Battlefront Valkyrie** is an near-exact phonetic match ("Battlefront" → "Battlefield/Battleship", "Valkyrie" → "Valgary"), and it is a miniatures battle game. Identification is high-confidence.

Fat Dragon Games publishes several other wargame titles, all rejected:

| Title | Why rejected |
|---|---|
| **Battle Hulks™** | Name shares "Battle" but not "Valkyrie". Self-described "a kinder, gentler wargame (except for all the bloodshed and killing)." No phonetic match to the dictation's second word. |
| **Slaughterscape™** | No phonetic overlap whatsoever. |
| **Alpha-Tech City™** | No phonetic overlap. |
| **Crown & Rebel™** | No phonetic overlap. |
| **World War Tesla™** | No phonetic overlap. |

**Caveat worth flagging to the user:** the task brief asked for a "skirmish/battle game," and Battlefront Valkyrie is a *fleet* game (you maneuver capital ships, not individual models on foot). If the user actually meant a person-scale skirmish game, **Battle Hulks** is the most likely alternative and should be re-checked. But the title match here is decisive.
