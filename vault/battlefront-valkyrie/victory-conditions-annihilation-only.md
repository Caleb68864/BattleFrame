# Victory Conditions: Annihilation Only — No Objectives, No Scoring

**The game has no objective or scoring system.** The only victory condition is destroying the enemy fleet.

Verbatim: "There are no scenarios other than '**destroy the enemy fleet**,' though objective-based scenarios are **hoped to be released in future products**."

This is a **confirmed negative** and an important one. As of the researched rules version there is:
- **No** objective markers or capture points.
- **No** victory point scoring track.
- **No** scenario library.
- **No** mission deck.

The rulebook does contemplate scenarios existing in principle — the FAQ says a drifting ship leaving the map is destroyed "**unless scenario rules state otherwise**" ([[drifting-and-voluntary-power-down]]), implying a scenario-override hook exists in the rules structure even though no scenarios ship with it.

**Engine note:** an architecture should treat scoring/objectives as a **planned-but-absent** extension point. The publisher has signalled intent to add objective-based scenarios. Build the hook; don't invent the rules.
