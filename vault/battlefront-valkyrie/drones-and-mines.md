# Drones and Mines: Point Costs

Beyond ships, fleets may include **drone groups** and **mine packs**, both bought with the same points budget ([[fleet-construction-points]]).

**Drones** — three types, bought in groups:

| Type | Cost |
|---|---|
| Drone A | 5 pts each |
| Drone B | 10 pts each |
| Drone C | 15 pts each |

**Mines** — sold in packs: **4 mines per pack, 5 pts per pack.**

**Marked `partial`:** these values come from the community fleet builder UI (bfv.cerkit.com), not the publisher's rulebook. They are concrete and specific, but should be confirmed against the rulebook before being treated as canonical — and they may drift as rules versions change ([[rulebook-availability-and-versions]]).

**Not found:**
- What each drone type actually *does* — the A/B/C distinction's mechanical meaning is unknown.
- Drone stats, movement, and whether drones activate independently.
- Mine deployment rules, trigger radius, and damage.
- Whether drone groups have a fixed size.
