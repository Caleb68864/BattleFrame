# Morale — Exists and Is Token-Tracked; Mechanics Not Public

Morale is a named subsystem in INCOUNTRY 2.0, but **almost nothing about how it works is publicly documented.**

**Confirmed:**
- Morale exists as a rule alongside suppression and leaning: reviews list "suppression, morale, and leaning out" as the depth-adding rules.
- "Suppression and morale tokens track unit status **without traditional health pools**" — https://blog.kaiscastle.com/2026/06/16/inx-incountry-review/ — consistent with binary model state ([[damage-armor-saves-and-headshots]]).

So morale is a **token-based status**, not a stat-check-and-flee system with a morale value on a card. That much is sourced.

## Unknowns (not found — do not guess these)

- What **triggers** a morale token (casualties? proximity? losing a leader?).
- What a morale token **does**.
- Whether morale tokens can be **removed**, and how. Notably, the control point sink list ([[control-point-economy]]) mentions removing **suppression** tokens and does **not** mention morale — so morale may clear by some other route, or not at all. **Unverified; do not assume symmetry with suppression.**
- Whether morale is per-model or per-team.
- Whether there is any leader/command influence on morale.

**No public source found describes morale's effect.** Written as "not found" deliberately rather than inferred from genre convention.
