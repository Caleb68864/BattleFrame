# Hidden Information and Fog of War — No Evidence Found

**This note records an absence, not a mechanic.**

The task brief flagged hidden movement, fog of war, and ambush as architecturally important because they break the "all state is visible" assumption. **No public source found describes any hidden movement, blind deployment, hidden unit, dummy marker, or fog-of-war system in INCOUNTRY.**

## What was actually found

Three mechanics touch on concealment or hidden state, but **none is confirmed as hidden information**:

1. **Command card selection** ([[command-card-initiative]]) — players "choose a command card" each round. If chosen **simultaneously and face-down**, this is genuine hidden information and the single most likely fog-of-war element in the game. **Reviews do not state whether selection is hidden or open.** Unresolved.
2. **Asset cards** ([[asset-cards-off-table-support]]) — if held as a hand before deployment, these are hidden. **Not stated.**
3. **Lean token** ([[lean-token-and-line-of-sight]]) — this is about *physical exposure and LOS*, not information hiding. The token itself is visible on the table. It complicates LOS geometry ([[lean-token-and-line-of-sight]]) but does **not** hide state.

## Assessment (inference — flagged as such)

Given a 2'x2' board, 3 units per side, and 30–45 minute games ([[table-size-and-game-length]]), INX is a **small, dense, fast** game where both forces start in mutual proximity and combat begins in round two. That design profile is **not typical** of games with hidden movement or ambush systems. My inference is that INX is largely an **open-state** game whose uncertainty comes from dice and from the reaction/initiative mind-game rather than from concealed information.

**This is an inference and is not confirmed by any source.** The command card question above must be resolved from the rulebook before an engine treats INX state as fully public.
