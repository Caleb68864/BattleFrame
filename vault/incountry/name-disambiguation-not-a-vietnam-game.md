# Name Disambiguation — INCOUNTRY Is Not a Vietnam Game

The phrase "in country" is Vietnam War soldier slang, which invites the assumption that a game called *InCountry* is a Vietnam game. **For this game that assumption is false.**

INCOUNTRY (INX) by Echo Dark Studios is a **contemporary / "ultramodern"** skirmish game. Its factions are fictional modern units — Blackthorn, Black Shell, Direwolf, Lion, Tiger Shark — and its terrain lines are modern (oil rig, shanty village). The rules product is explicitly titled "INX 2.0 **Modern Warfare** rules."

There is no Vietnam-era content in any public product listing.

## Other candidates found during identification

- **"In Country"** — a separate Vietnam War tabletop game listed on The Miniatures Page (http://theminiaturespage.com/rules/?id=456262), described as covering company- to battalion-level Vietnam combat. Publisher not determined; the TMP page could not be retrieved (TLS failure). **Not researched further.**
- **BOHICA** — Vietnam wargame rules sold by Empress Miniatures (https://www.empressminiatures.com/vietnam-war-bohica-wargames-rules-151-c.asp). Different game.
- **Bodycount** — Vietnam skirmish rules by Tabletop Games. Different game.

If the intent was a Vietnam-era engine reference, INCOUNTRY is the wrong source and "In Country" (TMP) is the candidate to chase.
