# Turnip28

Napoleonic-vegetable-apocalypse skirmish/small-battle game. Free rules, **license genuinely unknown** — do not assume open.

## Identity

- **Author:** Max FitzGerald (@maxstaxidermia)
- **Publisher:** Self-published via Patreon
- **URL:** https://www.patreon.com/Turnip28 — core rules posted publicly (v15 through v18 playtest)
- **Status:** Living document; latest confirmed public release v17, with a v18 playtest posted.

## Licensing — free, license NOT FOUND

**Unverified. Needs human legal review before any content ships.**

## Activation model — command-and-control, order-passing

**Partial** (from secondary sources; not verified against the rules PDF).

- Played in rounds; a typical game is ~4 rounds.
- Players **roll off for Initiative** at the start of the game (not each round — the initiative holder activates first each round).
- Within a round, players **alternate giving out orders until every unit has either given or received one order**.
- The interesting part: you activate a **commander (Snob)**, and that activation cascades to the units they command. **Uncommanded units activate only after all commanded units have gone.**
- "Make Ready" step fires when a Snob is chosen but before it issues orders — a hook point for Cult special abilities.

This is a genuinely distinct model: activation is **hierarchical and cascading**, not per-model. See [[activation-model-comparison]].

Sources: [hordesofthethings.blogspot.com](http://hordesofthethings.blogspot.com/2024/09/turnip-28.html), [Barrel Drill](https://www.barreldrill.com/turnip28-fortified-niche-playtest/), [Goonhammer interview](https://www.goonhammer.com/turnip28-interview-with-max-fitzgerald/).

## Complexity

Light-to-medium. Short rulebook, small model counts, ~4-round games. The command hierarchy is the main structural weight.

## Suitability

**Architecturally interesting, legally blocked.** The commander-cascade activation is a valuable stress test for an engine that assumes flat alternating activation. But with no license found, it cannot be an early *shipping* target. Good candidate for a permission request.
