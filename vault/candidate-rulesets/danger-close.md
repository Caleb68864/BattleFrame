# Danger Close

Tactical skirmish game whose **Basic Rules are CC BY-SA 4.0**. Alongside [[riot-dice-srd]], one of only two confirmed open licences found — and unlike Riot Dice, this one is actually implementable.

## Identity

- **Publisher:** Dice Goblin Games
- **URL:** https://dicegoblingames.itch.io/danger-close-tactical-skirmish-ttrpg

## Licensing — CC BY-SA 4.0 on the Basic Rules

**Confirmed.** Quoted from the itch.io page:

> "The basic rules are released under Creative Commons (CC BY-SA 4.0), so you're free to build on them."

The Basic Rules PDF is a **free download** *and* **openly licensed** — both categories at once, which is rare. See [[free-as-in-beer-vs-openly-licensed]].

**We could ship the Basic Rules content**, with attribution, subject to ShareAlike.

> [!important] ShareAlike is a real constraint, not a footnote
> **CC BY-SA** requires derivative works to be licensed under the same terms. Riot Dice's plain **CC BY** does not. Before building on Danger Close, get a human to answer: does a Foundry module embedding CC BY-SA rules text make the *module* a derivative work that must itself be CC BY-SA? This affects the licence of the surrounding engine code and is exactly the kind of question not to answer by inference. Practically, isolating CC BY-SA content in a clearly separated data package (rather than intermingling it with engine source) is the usual mitigation — but confirm with a lawyer.

### The tiering caveat

- **Basic Rules** — free, CC BY-SA 4.0 (confirmed)
- **"Commander's Toolkit"** (full/expanded product) — paid, $10+ PWYW. Its licence was **not verified**. **Do not assume the CC grant extends to it.** Treat as all-rights-reserved until checked. **Partial.**

The open grant is scoped to the free basic tier. This is the same "open core, paid expansion" shape as [[riot-dice-srd]], and the boundary must be respected precisely.

## Activation model

**Not found.** No source examined described Danger Close's turn structure or activation sequence. This is a gap, and given that it is one of only two viable open-licensed candidates, **closing it should be a priority** — the Basic Rules PDF is free and openly licensed, so simply reading it is both easy and legally unproblematic.

## Complexity

**Not established.** Billed as a tactical skirmish TTRPG; the free/paid split suggests a light core with optional depth. Unverified.

## Suitability

**The most promising early implementation target found in this survey**, on the strength of licensing alone — free, openly licensed, redistributable, and (unlike [[riot-dice-srd]]) not built on a physical dexterity mechanic that a VTT cannot represent.

**Caveat:** this ranks first largely because the field is so barren (see [[the-open-license-desert-in-miniatures-wargaming]]), not because it has been vetted as a good fit. Its mechanics, complexity, and community size are all **unknown**. Next step is to read the Basic Rules PDF and assess.
