# One Page Rules — covered elsewhere, deliberately not researched here

Placeholder so the candidate set is complete and this survey's omission is explicit rather than accidental.

## Scope note

**Grimdark Future, Age of Fantasy, and the rest of the One Page Rules catalogue were excluded from this survey by instruction** — a separate agent is researching them, and duplicating that work would waste effort and risk producing conflicting licence claims about the same games.

- **Publisher:** One Page Rules — https://www.onepagerules.com/
- **Everything else — licensing, activation model, complexity — is out of scope here.** See the `vault/one-page-rules/` notes.

> [!warning] Do not infer OPR's licensing from this vault
> Nothing in these notes should be read as a claim about OPR's terms. The [[licensing-freedom-ranking]] and [[activation-model-comparison]] tables **exclude OPR entirely** — its absence from them means "not researched," not "not suitable."

## Why it still matters to this survey's conclusions

Two open questions worth flagging for whoever reconciles the two vaults:

1. **[[the-open-license-desert-in-miniatures-wargaming]] counts three openly-licensed texts across ~20 games.** If OPR turns out to be genuinely openly licensed, that finding needs revising — and OPR would immediately become the strongest candidate in the whole space, given its size and active army data. If OPR is *free-as-in-beer only*, the desert finding stands and in fact strengthens: the hobby's flagship free-rules publisher would itself be closed.

2. **Its activation model belongs in [[activation-model-comparison]].** The table is a stress-test inventory; a gap that large weakens it.

**Action:** whoever holds both sets of findings should merge OPR into both comparison notes.
