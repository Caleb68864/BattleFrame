# OPR Rules Carry No Open Licence — Default All Rights Reserved

**The single most important finding.** One Page Rules publishes its rules **free of charge**, but has **not** released them under any open licence. Free-to-download is not free-to-redistribute.

Evidence gathered by fetching every candidate licence surface:

| Surface checked | Result |
|---|---|
| `onepagerules.com/terms-conditions` | Covers **Patreon STL files only** — see [[licence-terms-and-conditions-covers-stls-not-rules]] |
| Site-wide footer | `Copyright © onepagerules All Rights Reserved` |
| Free core rules PDF (GF v2.16) | **No copyright notice, no licence text at all** — see [[licence-rules-pdf-contains-no-licence-notice]] |
| `onepagerules.com/resources` | `Copyright © onepagerules All Rights Reserved`, no licence |
| Official GitHub org | No LICENSE file — see [[licence-official-github-repos-are-unlicensed-battlescribe-data]] |

Exact footer text, quoted verbatim from https://onepagerules.com/terms-conditions:

> Copyright ©  onepagerules All Rights Reserved

There is **no grant of redistribution rights anywhere on the site**. Under default copyright law, absent an express licence, the copyright holder reserves all rights. The practical consequence is [[licence-cannot-bundle-opr-rules-text-in-a-foundry-module]].

Do **not** rely on the widely repeated claim that OPR is CC BY-NC-SA — it is unsupported. See [[licence-the-cc-by-nc-sa-claim-is-a-false-positive]].

**Confidence: confirmed** for the absence of a licence on every surface checked. Note the limit of a negative finding: it proves no licence was *found* on the public surfaces enumerated above, not that none exists in some private channel (e.g. Patreon-tier terms, direct agreement). The correct resolution is [[licence-ask-opr-directly-is-the-only-clean-path]].
