# The Rules PDFs Are Explicitly "All Rights Reserved" — And Never Creative Commons

Both the current and legacy Grimdark Future core rules PDFs were downloaded and text-extracted directly. **Neither contains any licence grant. The current one is explicitly all-rights-reserved.**

## Current rules — GF Core Rules **v3.5.1** (the one that matters)

A footer appears on **every page**, quoted verbatim from the extracted text:

> Copyright © OPR Games. All Rights Reserved   |   Created By: Gaetano Ferrara   |   www.onepagerules.com

The **GF Beginner's Guide v3.5.1** (16pp) carries:

> Copyright © 2024 OPR Games - First Published 2024

Keyword scan over the full extracted text of both v3.5.1 documents:

| Term | Core Rules v3.5.1 | Beginner's Guide v3.5.1 |
|---|---|---|
| `copyright` | **Yes** | **Yes** |
| `all rights` | **Yes** | No |
| `creative commons` | **No** | **No** |
| `cc by` / `cc-by` | **No** | **No** |
| `licen` (licence/license) | **No** | **No** |
| `permission` | **No** | **No** |

So the current rules **assert copyright explicitly and grant nothing**. This is the cleanest possible refutation of [[licence-the-cc-by-nc-sa-claim-is-a-false-positive]] — a CC-licensed work must carry its licence notice; these carry the *opposite* notice.

## Legacy rules — GF Core Rules v2.16 (2022)

The older free one-pager is *silent* rather than restrictive — its only attribution text is a header, `By Gaetano Ferrara   www.onepagerules.com`, and a keyword scan returned **False for every** licensing term including `copyright` itself.

**Silence is not permission.** Under the Berne Convention copyright subsists automatically with no notice or registration required; the US ©-notice requirement was eliminated for works published after 1 March 1989. An unmarked document is still fully copyrighted. v2.16 is also **obsolete** — see [[mechanics-rules-versions-v2-vs-v3-differ-materially]].

## Net effect

Old rules: silent → all rights reserved by default. New rules: **explicitly** all rights reserved. Both roads lead to [[licence-opr-rules-have-no-open-licence]] and therefore [[licence-cannot-bundle-opr-rules-text-in-a-foundry-module]].
